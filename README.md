# Laboratorio 2

Pruebas de diferentes ejercicios comparando procesos secuenciales y paralelos.

## Distribucion:
En este codigo Lab2.c se encuentran las 3 partes y un menu que las controla.

En cada parte se pueden introducir ciertos parametros para poder probar y ver los diferentes tiempos en la comparacion de paralela y secuencial.

## Como compilar y correr el archivo

```

 Compilar: gcc -O2 -fopenmp Lab2.c -o lab2 -lpthread -lm
 Correr: ./lab2

```
